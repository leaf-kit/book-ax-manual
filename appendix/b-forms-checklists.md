# 부록 B. 체크리스트, 양식 전체 모음

본문에서 설명한 네 가지 양식을 복사해서 쓰는 형태로 모았다. 각 양식 앞에 어느 장과 함께 쓰는지 밝혀 둔다. 네 양식은 순서대로 이어진다. B-1로 업무를 쪼개고, B-2로 그 업무 중 어디부터 손댈지 고르고, B-3으로 착수할 조직이 준비됐는지 확인하고, B-4로 파일럿이 끝난 뒤 계속할지 정한다. 하나씩 따로 떼어 써도 되지만, 순서를 지키면 앞 단계에서 적은 내용이 다음 단계의 입력값이 된다.

## B-1. 업무 분해 워크시트

2.1과 함께 쓴다. 업무 하나를 작업 단위로 쪼갤 때, 어디까지가 AI에게 맡길 처리이고 어디서부터 사람이 판단해야 하는지를 가르는 칸이 "판단포인트"다. 이 칸이 비어 있으면 업무 전체를 통째로 AI에게 넘기거나 통째로 사람이 쥐고 있게 된다.

| 업무명 | 입력 | 처리 | 판단포인트 | 출력 |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

- 입력: 이 업무를 시작할 때 받는 자료, 데이터, 요청.
- 처리: 입력을 출력으로 바꾸는 단계. 반복되는 패턴이 있으면 AI-먼저 구조의 후보다.
- 판단포인트: 결과를 그대로 내보낼지, 사람이 검토해 수정하거나 중단할지를 정하는 지점.
- 출력: 처리가 끝나면 나오는 결과물과 받는 사람.

한 행에 판단포인트가 두 개 넘게 나오면 업무가 아직 덜 쪼개진 것이다. 행을 둘로 나눠 각각 다시 채운다.

## B-2. AX 적합도 진단 매트릭스

3.2와 함께 쓴다. 업무마다 임팩트와 실행 가능성을 1~5점으로 매겨 사분면 위에 배치한다. 두 축의 세부 질문은 3.2에 있다.

| 업무명 | 임팩트(1~5) | 실행 가능성(1~5) | 사분면 | 비고 |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

사분면 네 가지는 다음과 같다.

- 임팩트 높음 + 실행 가능성 높음: 바로 착수할 후보
- 임팩트 높음 + 실행 가능성 낮음: 준비가 필요한 전략 과제
- 임팩트 낮음 + 실행 가능성 높음: 작게 해볼 수 있지만 성과로 보여주기는 어려운 업무
- 임팩트 낮음 + 실행 가능성 낮음: 지금은 건드리지 않는다

## B-3. 조직 준비도 진단 체크리스트

3.3과 함께 쓴다. 데이터, 도구, 사람, 문화 네 축으로 나눠 묻는다. 축마다 "아니오"가 둘 이상이면 파일럿 착수 전에 그 축을 먼저 다룬다.

**데이터**
- [ ] 이 업무에 필요한 데이터가 시스템에 정리되어 있는가, 사람 머릿속에만 있는가
- [ ] 데이터 접근 권한을 실제로 쓸 사람에게 줄 수 있는가
- [ ] 데이터에 개인정보나 민감정보가 섞여 있고, 그 처리 방침이 정해져 있는가

**도구**
- [ ] 지금 보유한 도구로 이 업무를 처리할 수 있는가, 새로 도입해야 하는가
- [ ] 새 도구를 들이는 경우 승인과 구매 절차가 90일 안에 끝나는가
- [ ] 도구 사용 로그와 결과를 추적할 수 있는가

**사람**
- [ ] 이 업무를 실제로 하는 사람이 재설계에 동의했거나, 동의를 구할 절차가 있는가
- [ ] 파일럿을 이끌 담당자가 정해져 있는가
- [ ] 참여자가 새 업무 흐름을 배울 시간이 일정에 반영되어 있는가

**문화**
- [ ] 실패한 파일럿을 공유해도 불이익이 없다는 것이 조직에서 통용되는가
- [ ] 경영진이 90일 동안 중간 결과를 기다려 줄 수 있는가
- [ ] 다른 부서의 비슷한 시도와 결과를 공유하는 통로가 있는가

## B-4. 파일럿 평가 스코어카드

4.5, 8.3과 함께 쓴다. 90일이 끝나는 시점에 확산할지, 중단할지, 조정 후 재시도할지를 정하는 카드다.

| 항목 | 측정값 | 베이스라인 대비 | Go / No-go 판단 |
|---|---|---|---|
| 처리 시간 또는 처리량 | | | |
| 오류율 또는 품질 지표 | | | |
| 참여자 만족도 또는 채택률 | | | |
| 예상치 못한 리스크 발생 여부 | | | |

- [ ] 측정값이 베이스라인과 같은 기준으로 비교되었는가
- [ ] 목표로 삼았던 성과 지표(1부, 3.2)와 연결되는가
- [ ] 중단이나 조정이 필요한 리스크 신호(4.6)가 없는가
- [ ] Go, No-go, 조정 후 재시도 중 하나로 결론을 냈는가
